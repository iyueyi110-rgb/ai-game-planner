# AI 叙事游戏策划助手

AI 叙事游戏策划助手是一款面向游戏策划流程的互动网页工具。用户可以通过选择游戏类型、玩法重点和世界观风格，快速生成一份包含剧情设定、任务流程、系统机制和玩家分支的游戏策划方案。

## 核心价值

该项目模拟了 AI 在游戏前期创意设计中的应用，重点展示：
- **AI 辅助策划** — 基于用户选择自动生成结构化策划文档
- **交互式生成** — 多步骤选择 → 生成动画 → 结果展示的完整交互流程
- **结构化内容输出** — 世界观、主角设定、核心玩法、任务流程、玩家分支、奖励系统六大板块

## 技术栈

React 19 + TypeScript + Vite，纯前端 mock AI 生成，不依赖外部 API。

**Why:** 这是一个作品集/展示项目，目标是体现 AI 产品经理或游戏策划的技术审美和产品思维。
**How to apply:** 后续开发应围绕"AI 辅助创意"这个核心叙事，保持交互的流畅感和内容的专业性。
